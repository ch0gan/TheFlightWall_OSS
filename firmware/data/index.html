API keys
Flightradar24 is an unofficial scrape of fr24.com for personal use only — it can break or rate-limit, and rows with a route skip the separate enrichment lookup (rows without one, mostly GA/unscheduled traffic, still use it). Best on the S3 (PSRAM). adsb.lol is a free, keyless, community-run ADS-B aggregator — no account, no ToS problem, and it carries aircraft type and registration inline, but no route (enrichment below still runs for that). The FlightWall server is infrastructure you deploy yourself: one HTTP call per cycle returns routes, airline names and ETA already computed, and it falls back to adsb.lol for that cycle if it can't be reached. OpenSky stays the default.
